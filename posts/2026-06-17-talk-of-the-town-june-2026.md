[**Kevin Suh**](https://www.val.town/u/kevinsuh) built a
[spend-agent](https://www.val.town/x/kevinsuh/spend-agent) personal finance val.
He likens it to Claude Code for Mint, connecting credit cards and categorizing
transactions then making that structured data accessible for you to build on top
of. It's a nice example of an open source, free SaaS alternative hosted on Val
Town.

## Vals from the Val Town team

[**Charlie**](https://x.com/CharlieMolthrop)
[hosted an open mic night for ten LLMs](https://x.com/CharlieMolthrop/status/2059772171354882284),
which incidentally won him OpenRouter's weekly $50 credit prize. Spoiler:
Charlie is funnier than the models.

![open-mic.png](https://imagedelivery.net/iHX6Ovru0O7AjmyT5yZRoA/98848e57-b79d-4b10-3cc0-727b9942f900/public)

More Charlie work:

- The [vapi-phone-call](https://www.val.town/x/templates/vapi-phone-call)
  template solicits an AI (gpt-4o) phone call via the Vapi API. For example,
  Charlie's [call-my-human](https://www.val.town/x/dcm31/call-my-human) val is
  an MCP server that allows an agent to call you mid run if it has a question
  for you
- [artifact-slackbot](https://www.val.town/x/dcm31/artifact-slackbot) is a val
  that ingests data and generates HTML artifacts right from Slack
- When Opus 4.8 dropped, Charlie
  [tested it against Meryl Streep's demands](https://x.com/CharlieMolthrop/status/2060153658134667531)
  from The Devil Wears Prada
- By hooking up OpenAI realtime to the Val Town MCP server, Charlie
  [created an HTML slide deck by speaking plain English](https://x.com/CharlieMolthrop/status/2057217297404592271).
  You can create webpages with your voice at
  [talk.val.run](https://talk.val.run/)
- [skillbook.val.run](https://skillbook.val.run/) is a trading card-themed agent
  skill repo
- [farm-log](https://www.val.town/x/dcm31/farm-log) is an indoor-garden tracker
  ([charlies-farm-log.val.run](https://charlies-farm-log.val.run/))

---

[**Steve**](https://stevekrouse.com/) had to fax the IRS, so he vibe coded
[agentfax.val.run](https://agentfax.val.run/) which wraps a fax API in a
[Tempo](https://tempo.xyz/) proxy. Agentfax has sent 28 faxes for $7.80 ($6.05
profit) since launching a couple weeks ago. _(Fun fact: I learned last week that
fax is short for facsimile.)_

![agentfax.png](https://imagedelivery.net/iHX6Ovru0O7AjmyT5yZRoA/7fc9cd07-03bf-4921-04bc-0eab52445200/public)

Steve also made:

- [blob-bench](https://www.val.town/x/valdottown/blob-bench) benchmarks Val
  Town's new S3-based [scoped blob storage](/scoped-blob-storage) against the
  legacy R2-based blob storage (tl;dr - it's now 5x faster)
- [a stripe-mirror template](https://www.val.town/x/templates/stripe-mirror) to
  make working with your ARR data from Stripe a whole lot easier (e.g. for
  revenue analytics)
- [a secret sharing app](https://x.com/KeshavY93629914/status/2060204305844732030),
  like magic-wormhole but web-based and remixable
- [four app prototypes in ten minutes](https://x.com/stevekrouse/status/2059387694388539853?s=20)
  using the (relatively) new [Stripe Projects](https://projects.dev/) with Val
  Town MCP + Claude Code
- [a Claude Managed Agents UI template](https://www.val.town/x/templates/claude-managed-agents-ui)
  (read: OSS Lovable-like app builder)
- [a Claude Managed Agents UI + Val Town MCP template](https://www.val.town/x/templates/claude-managed-townie)
  (remixing the above)
