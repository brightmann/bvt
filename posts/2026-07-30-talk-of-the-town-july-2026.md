[**Paul Chin Jr.**](https://paulchinjr.com/) made
[laval.val.run](https://laval.val.run/) to simulate fluid in a lava lamp.

<img
  src="/images/47565831-b746-4a98-9119-90d721649400.webp"
  alt="a lava lamp particle simulation"
  style="border-radius: 4px; border: 2px solid var(--orange);"
/>

And some kind words from Paul about using the Val Town plugin with ChatGPT Work
(emphasis mine):

> **Hooking up valtown to chatgpt work has really insanely good ergonomics.**
> I’ve been learning fluid sims. Before I was using ChatGPT to learn, and using
> Codex to implement, but now I can use ChatGPT Work w/ Val Town plugin and I
> basically get both in the same interface. I’ve sidestepped git, because
> valtown has a good enough code repo, and everything deploys pretty quick. I
> was rate limited once by valtown, and it eventually cleared up again the next
> day. **Overall, I’m super impressed because I’ve used all the other vibe
> coding platforms like lovable and repplit, and valtown is more flexible and
> powerful.**

**Eryn Montgomery** made

is better than I expected (maybe because it rips its sources?). At least it
lists sources and doesn’t [pretend it’s human](/ethical-cold-outreach)—the val’s
description is "automated obituaries," so I appreciate the candor.
